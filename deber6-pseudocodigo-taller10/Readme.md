Pseudocódigo — Sistema de Evaluación Docente con IA

Este pseudocódigo representa el flujo completo del diagrama proporcionado.

El archivo principal es pseudocodigo_evaluacion_docente.psc.

Flujo implementado

Inicio.

Ingreso del nombre del docente.

Ingreso de la materia.

Ingreso de la descripción de la actividad o evaluación.

Validación de campos obligatorios.

Si falta información, se muestra un mensaje y se vuelve al ingreso de datos.

Si los datos están completos, se envían a la IA.

La IA analiza la actividad docente.

Se generan resultados para Recursos Digitales.

Se generan resultados para Evaluación.

Se generan resultados para Empoderamiento del Estudiante.

Cada dimensión contiene nivel (1-2-3), justificación y sugerencia.

Se genera el informe final.

Se muestran los resultados al usuario.

Fin.
